### Added
- Inline genesis: the `init.genesis` config field holds a genesis document in the same format as a genesis json file, so a single config file can boot a new chain. The new `init.genesis-mode` option (`inline`, `file` or `directory`) selects the genesis source explicitly; when unset, the first configured source is used, in the order: `init.genesis`, `init.genesis-json-file`, `init.genesis-json-file-directory`. Genesis documents supplied by name (file or inline) are now verified to target the configured chain ID and to use `serializedChainConfig`, as directory-discovered ones already were.
